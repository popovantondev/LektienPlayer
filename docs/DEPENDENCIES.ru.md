# Сторонние компоненты

Swift 6.1 / Xcode 16.4; SwiftUI, AppKit, AVFoundation, CryptoKit; FFmpeg/FFprobe; whisper.cpp / Whisper / Silero VAD; TDLib; Codex CLI; system Ruby; Python, Torch, Silero TTS (Kseniya).

Kseniya сейчас ожидает готовое окружение Python в ~/Library/Application Support/SRTVoiceover/.venv-silero с Python/Torch/Silero и моделью голоса. Codex CLI нужно установить и авторизовать отдельно. Используется также системный Ruby. Сборка исходников сама эти компоненты не устанавливает. Учётные данные и виртуальное окружение между компьютерами не копируйте.

Лицензия проекта не назначена. Открытая публикация исходников сама по себе не даёт разрешения на распространение или смену лицензии. У сторонних компонентов сохраняются их собственные условия.
