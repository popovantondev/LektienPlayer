# Drittkomponenten

Swift 6.1 / Xcode 16.4; SwiftUI, AppKit, AVFoundation, CryptoKit; FFmpeg/FFprobe; whisper.cpp / Whisper / Silero VAD; TDLib; Codex CLI; system Ruby; Python, Torch, Silero TTS (Kseniya).

Kseniya erwartet derzeit eine vorhandene Python-Umgebung unter ~/Library/Application Support/SRTVoiceover/.venv-silero mit Python/Torch/Silero und dem Sprachmodell. Codex CLI muss separat installiert und angemeldet werden. System-Ruby wird ebenfalls verwendet. Ein Quellcode-Build installiert diese Komponenten nicht. Zugangsdaten und virtuelle Umgebungen nicht zwischen Rechnern kopieren.

Dem Projekt wurde keine Lizenz zugewiesen. Die öffentliche Verfügbarkeit des Quellcodes allein erteilt keine Erlaubnis zur Weiterverbreitung oder Neulizenzierung. Für Drittkomponenten gelten deren eigene Bedingungen.
