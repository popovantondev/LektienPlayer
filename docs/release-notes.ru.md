## Установка

Прочитайте руководство и BUILD.ru.md. Соберите исходники через swift build; полная .app требует подготовленных компонентов Runtime. Откройте видео, выберите субтитры или немецкую звуковую дорожку и запустите перевод.

## Ограничения

Только исходники, готового установщика нет. macOS 15+, Apple Silicon, Xcode 16.4+ / Swift 6.1. Для полной работы нужны отдельный Runtime, Codex CLI с входом ChatGPT и Python/Torch/Silero Kseniya. Установка на чистый Mac пока не проверена.
