# Права и разрешённое использование

[English](RIGHTS.md) · [Deutsch](RIGHTS.de.md) · Русская версия

Если автор проекта не добавит отдельную лицензию, исходный код этого репозитория опубликован только для публичного просмотра. Разрешение копировать, изменять, распространять, сублицензировать или продавать исходный код проекта и его изменённые версии не предоставляется.

Автор проекта разрешает частным лицам скачивать и использовать для личных целей неизменённую бинарную версию релиза; сейчас бинарный выпуск не публикуется. Это разрешение не заменяет права и уведомления для сторонних компонентов, перечисленные в [THIRD_PARTY.md](THIRD_PARTY.md).

Условия сервиса GitHub могут разрешать просмотр и создание форков на платформе. Форк не даёт дополнительных прав на использование проекта за пределами функций платформы.
